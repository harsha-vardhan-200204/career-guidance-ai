# 🎯 Smart Career Guidance System

An AI-powered career guidance platform that helps students and job seekers discover suitable career paths based on their interests, skills, education, and career goals.

## 🌐 Live Demo

🚀 https://smart-career-guidance-system-3f8e34099.vercel.app/

---

## 📖 Overview

Smart Career Guidance System is an intelligent web application designed to assist students and professionals in making informed career decisions. The platform analyzes user preferences, skills, and interests to provide personalized career recommendations and learning pathways.

The system aims to bridge the gap between education and career opportunities by offering data-driven guidance and career insights.

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/smart-career-guidance-system.git
```

### Navigate to the Project Folder

```bash
cd smart-career-guidance-system
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm start
```

The application will run at:

```text
http://localhost:3000
```
